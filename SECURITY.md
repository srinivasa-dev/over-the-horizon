# Security Policy

## Supported Versions

We release security and bug fixes for the current active release line.

| Version | Supported          |
| ------- | ------------------ |
| 2.2.x   | :white_check_mark: |
| 2.1.x   | :white_check_mark: |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or security bug in **Over The Horizon**, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email to `security@overthehorizon.dev` detailing:
   - Description of the vulnerability.
   - Steps to reproduce the issue (including browser version, OS, and GPU if WebGL related).
   - Potential impact or proof of concept.
3. We will acknowledge receipt of your report within 48 hours and coordinate a disclosure schedule and patch release.
